# Preserved effects references

Test-only original Phosphor Echo round-3 and CRT Glass Motion previews, plus the owner-captured settings export. The owner approved this visual subset for public CLEAR fixtures on November 2, 2026. `SOURCE-MANIFEST.json` records the original byte hashes; these are not regenerated fixtures.

The four JPEGs show the same sample Generate form. Its workout values and note are specimen text, with no identified account or user history. Credentials, original annotated attachments and workflow handoff material are excluded.

`crt-iab-current-settings.json` is the approved current numerical source. `crt-glass-motion/working-session.mjs` remains solely because the preserved host imports it; tests override its earlier trial settings with the captured export.

PixiJS 8.22.0 and pixi-filters 6.1.5 retain their MIT license files and bundled notices. The Oxanium, Space Grotesk and Rajdhani font families retain their OFL notices under `FONT-NOTICES/`. CLEAR preview source has no separate permissive license declaration.

The shared test resolver defaults to this directory. Explicit reference and settings environment paths remain supported for comparison against separately preserved inputs. These files do not enter the application bundle.
