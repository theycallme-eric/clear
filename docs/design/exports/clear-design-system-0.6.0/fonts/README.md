# Fonts

CLEAR uses three Google Fonts — loaded via CDN in `colors_and_type.css`:

- **Rajdhani** 500 / 600 / 700 — Headings
- **Oxanium** 400 / 500 / 600 / 700 — Labels, CTAs, timers
- **Space Grotesk** 400 / 500 / 700 — Body

No local TTFs are shipped. If offline use is required, download from Google Fonts and drop the `.ttf` / `.woff2` files here, then swap the `@import` in `colors_and_type.css` for `@font-face` declarations.

**No substitutions were made** — the originals are all freely available on Google Fonts.
