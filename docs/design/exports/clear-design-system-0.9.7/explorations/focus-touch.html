Focus on touch screens
On a phone, tapping a button or chip never shows a focus indicator; browsers only show it for keyboards. The one place it appears on touch is a text field, because tapping a field always counts as focus. Each screen below shows the moment after tapping the Note field, with the keyboard up. The chip is selected, so you can check focus and selected stay apart.
Skin
Where D still appears on touch devices: only when someone uses a hardware keyboard with a tablet or phone, or switch access. Screen readers (VoiceOver, TalkBack) draw their own focus indicator on top, so ours doesn't need to do anything for them.
On C: leaving a focused field without an indicator is allowed if the caret is visible, but it's the weakest option for accessibility. On a bright field in bright sunlight, a thin blinking caret can be the only cue.
