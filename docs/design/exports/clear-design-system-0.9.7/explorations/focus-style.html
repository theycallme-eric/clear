Focus style
This is what keyboard users see on the control they're about to use. Each option shows the same four controls, with only the focus treatment changing. Show all focused is on so you can compare at a glance. Turn it off and press Tab to move through them for real. In every option focus snaps on; it's never animated.
Skin
A has a second problem beyond looking jarring. Chamfered controls are cut to shape, and that cut also clips anything drawn outside them, including this outline. On the button and chip in A you'll likely see no ring at all, which fails keyboard users. The other three draw inside the shape (B, C) or on a wrapper (D), so they aren't clipped.

Requirement for any pick: the focused state must differ from the unfocused state by at least 3:1. B and C change a border that is sometimes already bright, so they don't always clear it; focus-vs-selected.html measures this.
