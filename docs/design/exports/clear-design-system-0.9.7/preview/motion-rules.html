Motion Rules
Every rule on this card is shown working, not described. Interface motion is linear or stepped, never eased. Motion can reinforce state, but it is never the only cue.
1 · Interaction timingHover over a button, hold it, tab to it
Hover · --dur-hover 200ms
Surface and border step to the hover rung over 200ms, linear.
Press · --dur-press 0ms
Hard cut to one rung above hover. No transition, no shrink, no movement.
Toggle · --dur-state 100ms
A control that holds a state changes over 100ms.
Focus · never animated
The ring snaps on. Focus has to be visible the moment it lands.
2 · Each effect has one meaningClick a tile. Don't borrow an effect for a different meaning.
Set failed
Glitch = failure
Sensor
CRT off = switched off
Old entry
Phosphor decay = leaving
Reading
Scan = loading or reading
3 · A state change interrupts: cut, then interlaceNothing waits on an animation
Idle
A list starts to reveal and new data arrives partway through. The reveal is dropped at once, and the new state arrives with a 100ms .clr-interlace re-sync. The old animation never finishes and never reverses.
