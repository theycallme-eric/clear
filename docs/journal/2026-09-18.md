## What changed

- `src/test/render.tsx` — new. `AppProviders` is the single place app-level providers mount;
  `renderWithProviders(ui)` wraps a component in providers plus a `MemoryRouter`;
  `renderApp(entries)` mounts the real route tree via `createTestRouter`.
- `src/test/factories.ts` — new. Domain fixture factories; currently `makeAppError` built on
  `createError` from `src/state/errors.ts` with partial overrides.
- `src/test/example.test.tsx` — new. The ENV-06 example component test: renders the design-system
  `Checkbox` (public entry) through the helper, queries `getByRole('checkbox', { name })`, operates
  it with `userEvent`, and asserts checked state and visible label; second case proves fixtures
  come from the factory.
- `src/app/router.test.tsx` — refactored to use `renderApp` instead of hand-mounting
  `RouterProvider`, per the "utilities live in one place" criterion.
- `vite.config.ts` — coverage config (v8 provider, text/html/lcov reporters, no thresholds;
  excludes the vendored `src/design-system/**`, test utilities, and `main.tsx`).
- `package.json` — added `test:coverage` script (`vitest run --coverage`).
- `DEVELOPMENT.md` — new, scoped to the harness: watch loop, test-writing rules, coverage. ENV-04
  will add the environment-setup content later; the header says so to avoid a scope collision.
