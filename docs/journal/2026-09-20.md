# 2026-09-20 — Protected Agent Runner autopilot transition

## Intended outcome

Allow the externally controlled Agent Runner to drain the approved CLEAR dependency graph without
requiring a person to merge every safe node, while preserving strict branch protection and explicit
human gates for workflow changes, database migrations, live backend mutation, and final release.

## One-time transition

- Merged the previously reviewed backend-audit, test-harness, and structured-logger candidates in
  dependency-safe order after rebasing each branch, preserving their append-only journal entries,
  and rerunning the full project verification suite.
- Changed the CI `pull_request` trigger to the statically provable automatic lane: unfiltered
  `opened` and `synchronize` events. Required Typecheck, Lint, Test, and Build jobs remain unchanged.
- Branch protection remains strict, applies to administrators, pins every required check to GitHub
  Actions, and requires no approving review that an unattended lane could bypass.

## Safety boundary

The automatic policy lives in the external Runner contract, not this product repository. The
Runner must still prove the exact protected workflow and branch policy before each automatic lane
and immediately before every merge. Changes under `.github/workflows/**` and
`supabase/migrations/**` remain protected human gates.
