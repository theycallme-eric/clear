The requirement names oxlint. The workspace has no network access — `npm install`, `npm view`,

devDependency, which implements `no-restricted-syntax` and `no-restricted-imports` with the
same esquery selector semantics the export's rules are written against. Nothing about the rule
set is retyped: `scripts/adherence/ds-config.mjs` reads the vendored JSON and raises it.

oxlint binary is wanted specifically, it needs a dependency added in an environment with a
