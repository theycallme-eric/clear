## TASK-005 / #351 — shell, atmosphere and app global styles on 0.14.3

Intended outcome: the root shell, Screen, atmosphere adapters and `src/styles/**`

Starting point: TASK-002 had already vendored 0.14.3 byte-for-byte (the vendored
`foundation.css` and `motion.css` equal the evidence copies), so longer-side
`cqmax` blobs, transform-only breathing, the 70% card ground and the 1.25 body
steps were already shipped. The work was removing app-owned rules that
overrode or duplicated them.

What changed locally:

- `src/styles/atmosphere.css` — removed the portrait `max-aspect-ratio` block
  that re-sized and re-positioned the three blobs by width. It predated `cqmax`
  and was overriding the shipped longer-side geometry on every phone. The
  `data-static` reduced-motion rule stays.
- `src/app/atmosphere.ts` — removed the per-screen `SCREEN_ATMOSPHERE` table and
  the throwing lookup. `resolveAtmosphere` and `screenAtmosphere` remain as
  constant functions because unowned consumers import them.
- `src/styles/skin-clear.css` — removed the retired font aliases and the legacy
  primitive colour block, which 0.14.3's own skin no longer declares.
- `src/styles/a11y.css` — the skip link read the retired `--font-label`; it now
  reads `--font-data`. Found by the new alias assertion, not by inspection:
  deleting the alias alone would have silently dropped the skip link's font.
- `src/styles/shell.css` — removed the `.clr-actions` adapters; the package now
  ships the same full-width and primary-placement rules.
- `src/app/RootLayout.tsx`, `src/ui/atmosphere.tsx` — comments only.
- Tests: `src/app/atmosphere.test.tsx`, `src/app/contained-shell.test.tsx`,
  `e2e/contained-shell.spec.ts`. The browser spec now measures pinned-footer
  geometry and layer transparency at four viewports, blob size against the
  longer side, the animated properties of drift and breathing, the static
  reduced-motion state, and fonts/ground/emission under all four skins.
