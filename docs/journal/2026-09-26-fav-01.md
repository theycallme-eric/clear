## Intended outcome

Save a completed workout as a favorite from the Summary screen, list favorites on Home with
anchor/intensity/duration, restart one into Review from its snapshot with no generation call, and
bump `times_completed` when a restarted favorite is completed — with the snapshot validated
against the schema for the version *it states* before restore.

## Why attempt 1 failed, and what prevents a repeat

Adding a table is not only a migration. Three standing checks derive from the migrations and fail
when the register behind them has not been told:

- `scripts/e2e/dispositions.mjs` — every table needs an explicit `cross-user` /
  `shared-reference` disposition (`src/test/rls-standing-matrix.test.ts`).
- `scripts/e2e/namespace.mjs` — every `cross-user` table needs a row selector and a forged row
  (`src/test/e2e-lifecycle.test.ts`, which also holds the ordered table list).
- `src/test/generated-types.test.ts` — the table list, the migration-file list, and byte-identity
  with the generator's output.

Attempt 1 also marked both tables `seeded: true`, which the harness cannot honour: a favorite's
snapshot names catalog exercise ids and the catalog is applied by its own task, so reset left rows
behind. Both are `seeded: false` here with that reason recorded, matching `workout_exercises` and
`exercise_set_logs`.

## What landed

  `snapshot_contract_version` + the list metadata + denormalized counters),
  `saved_workout_completions` (one row per attempt, `completed_at` null until the session
  finishes), RLS in DATA-01c's posture, and two functions: `save_favorite` (favorite + first
  attempt in one transaction, idempotent on re-favoriting) and `record_favorite_completion`

  `SNAPSHOT_SCHEMAS` + `snapshotSchemaFor` (the version registry that makes "validated against the

  `savedWorkoutRowSchema` / `savedWorkoutListSchema` / `savedWorkoutDraftSchema`, the favorite
  outcome vocabulary.
- `src/data/favorites.ts` — `FavoritesClient`: list, save (RPC), attempt (insert),
  recordCompletion (RPC), remove (delete, cascade takes the progression).

- The three standing lists above, updated.
