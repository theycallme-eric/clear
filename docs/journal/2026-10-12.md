## TASK-024 / #370 — Places and equipment on the shared card and pinned-action grammar

`src/app/LocationSettings*` and `e2e/settings-locations.spec.ts`. The list, editor, empty, error,

What changed locally.

    list-level save line used to float between the title and the cards; each now lives in the card
    it is about.
  - A place is one `Card` through the adapter's `heading` (the name, a real level-2 heading) and
    `meta` (the tier). The default carries a tick glyph, "Default for generation", and the sentence
    "Generation uses this place and the equipment saved with it."
  - Card actions: Edit is the public `TextAction`; Make default and Delete are framed secondary
    buttons in one `CardActions` row, replacing a `clr-row` with an inline `flexWrap`.
  - A deletion refusal renders as a glyph-and-sentence alert inside the refused place's card. The
    save line renders in the card whose action started the write.

    error (`ErrorView` with Retry) render inside it instead of as bare paragraphs, and the fields
    are a real `<form>` wired to the shared `useInvalidFocus`.
  - Pinned footer by state: Add place (list), Save place + Cancel (editor; Cancel alone until the
    equipment has been read), Retry (failed places read). Save place submits the form by `form=`,
    the pattern Login uses. Previously nothing was pinned while the editor was open.
  - The places-read loading state is `LoadingView` (ScanLoader) instead of a bare paragraph.
  - The list arrives through the shared `useArrivalStagger`.
