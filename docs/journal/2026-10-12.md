What changed locally.

- `src/ui/conditioning-score.tsx` — the score is the shared `MetricFrame` readout instead of a
  bare stack: one small element frame where it stands in the effort dialog, a bare readout inside
  a card, so it never floats and never nests a card. The score line is in the data face; the
  comparison / absence line is secondary text. Every string, and the rule that a comparison is
  rendered only when one was computed, is unchanged.
- `src/ui/block-effort.tsx` — the dialog body is one `clr-stack` at the system's group rhythm
  (summary, score readout, the one slider field) in place of the tight stack with inline flex.
  Title, summary copy, default effort, reset-on-open, slider focus, action order and the
  `onConfirm` / `onCancel` / `saving` contract are unchanged.
- `src/ui/exercise-swap.tsx` — "Swap" and "Undo swap" on a movement are the public `TextAction`
  instead of quiet `Button`s: no frame inside the block's card, 40px target, same accessible
  names, same `open` / `undo` calls with the slot id. The dialog's alternatives are the same
  framed secondary choices; their inline styles moved to named constants with the same token
  values.
- Tests: new `exercise-swap.test.tsx` (17); `block-effort.test.tsx` 9 → 15;
  `conditioning-score.test.tsx` +3.

Visible differences, stated so they are reviewed rather than discovered.

- The swap controls lose their frame and gain the `TextAction` chevron; the refresh glyph stays
  on "Swap" at 16px.
- **Busy state.** `TextAction` has no `loading` prop. While a swap or undo is in flight the
  controls are `disabled` with `aria-busy="true"` — the same two attributes the quiet `Button`
  set — but the button's scan sweep is gone. Nothing loops on the movement row; the dialog's
  loader is the one loop.
- The score in the effort dialog now sits in a chamfered element frame, and the dialog's groups
  are spaced at `--spacing-400` rather than `--spacing-200`.
