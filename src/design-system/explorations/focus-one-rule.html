Focus: combining A and B
Two ways to make brackets and a lit border into one rule. Each shows a focused text field and a focused selected chip, on keyboard (desktop) and touch (phone). The chip is the hard case for keeping focus and selected apart.
Skin
ASplit by control type
Controls that can be selected (chips, tabs, buttons) get brackets. Controls that can't be selected (text fields) light their border. Same on every device.

Each control has exactly one focus style, whatever the device. Fields look the same on desktop and phone. On touch, chips show no focus at all, as browsers intend.
Recommended: simplest rule, still keeps focus and selected apart
