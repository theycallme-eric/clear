# R3 shared owners and remaining contracts

| Owner | What is shared | Context-specific behavior |
| --- | --- | --- |
| MovementGroupHeader / movement-group CSS | Static title/badge arrangement and group spacing | Review is always expanded; live navigation/progress remains outside the group header |
| MovementIdentity / MovementList | Name, prescribed target/load, quiet equipment, peer separators | Review supplies Swap; live supplies counter and logging/rest; saved detail retains actual results |
| EquipmentSummary / SummaryFacts | Compact wrapping factual readings and equipment grouping | Equipment/icon treatment is a new first pass; stored meanings remain unchanged |
| BlockPanel / GroupExerciseCoaching | One bottom grouped disclosure | Existing per-movement Guidance and notes writers/drafts/errors remain separate |
| SectionHeader compact variant | One compact navigator using the existing jump state | Focus follows the newly opened group heading; no section completion is inferred |
| CountdownBar / PreparationGuide | Accepted concise guide and matching timer presentation | Rest and preparation keep independent clocks |

The running R01–R37 checklist is the handoff source. Later choices explicitly supersede earlier placements. Accepted appearance does not establish guide generation, load-range persistence, adaptive-report calculations, hidden setup defaults or live logging receipts. Resolve these as ordinary requirements before implementation; do not silently infer them from a synthetic fixture.
