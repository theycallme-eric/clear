# _source/: historical reference only

**Do not copy patterns, values or components from this folder.**

These are the workout application's original components, from before CLEAR was a design system. They're kept as provenance: where the system's shapes, motion and copy voice came from. They predate every calibrated decision, so they still contain things the system has since ruled out, including:

- an SVG chamfered frame with an open left edge and a pulsing accent bar;
- glow on timers, text and boxes;
- a spinner and skeleton bars for loading;
- per-screen atmosphere modes;
- hard-coded colours and sizes.

For anything you build, use the system instead: the components in `components/`, the classes in `css/`, the rules in `README.md`, and `ui_kits/app/` for a full worked example.

Nothing in this folder is compiled into the system's bundle.
